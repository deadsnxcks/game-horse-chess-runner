# Смоук-проверка horsechess

## Когда применять

После любой правки, которая влияет на то, что видит или чувствует игрок: ходы, взятия, фазы, смерть, рестарт, счёт и рекорд, звук, пауза, мобильный вид. Для правок вида «поправил комментарий» не нужно.

## Порядок

1. `npm run typecheck` — код возврата, не «выглядит нормально».
2. `npm run build` — прод-сборка должна проходить.
3. `npm run preview` — игра открывается на `http://localhost:4173/`.
4. `node .opencode/skills/horsechess-smoke/scripts/smoke.mjs http://localhost:4173/` — если Playwright установлен.

Скрипт сам открывает мобильный вьюпорт, слушает ошибки консоли и 404, делает скриншоты в `/tmp/horsechess-smoke/<время>/`, печатает результат и выходит с кодом 0 или 1.

### Если Playwright нет

Скрипт скажет `playwright не установлен` и выйдет с кодом 2. Это не повод ставить пакет молча: сначала спроси разрешение — `npm i -D playwright && npx playwright install chromium` (около 150 МБ). До установки прогоняй ручные пункты.

## Чеклист

Автоматически (скрипт):

- страница открывается, в консоли нет ошибок;
- нет 404 по ассетам;
- canvas существует и имеет ненулевой размер;
- тап/клик по полю не роняет игру;
- 12 случайных тапов подряд не вызывают исключений;
- после перезагрузки страница снова запускается.

Руками (30 секунд):

- ход конём делается только буквой «Г», подсветка точек верная;
- взятие фигуры начисляет её ценность и останавливает экран в фазе «Охота»;
- смерть от фигуры и от красной полосы срабатывает и показывает экран проигрыша;
- «Ещё раз» начинает новую игру с фазы 1;
- рекорд сохраняется после перезагрузки вкладки;
- сворачивание вкладки ставит игру на паузу, возврат продолжает;
- звук выключается и включается на паузе;
- на телефоне (или в DevTools 390×844) ничего не уезжает и не обрезается.

## Как отчитываться

Каждый пункт: `ok` / `fail` / `not checked` и доказательство — команда с кодом возврата, путь к скриншоту или «не проверено, потому что …». Итог одной строкой: можно показывать или нет и что именно блокирует.
